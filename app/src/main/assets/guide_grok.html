Grok（xAI）を
登録して使う方法

要点：Grok（xAI）のAPIは使った分だけ払う方式で、新規アカウントに特典のクレジットがつくことがあります（額や条件は変わります。データ共有への同意が条件のこともあります）。X Premium や SuperGrok の月額プランとは別の契約です。

① お金の流れ

1回特典のクレジットを受け取る／クレジットを購入金額と有効期限はコンソールの画面で確認
残高に入るAPI専用です
話すたびに少し減るGrok 4.1 Fast なら1往復で1円未満
残高が0で止まる自動チャージ（Auto-recharge）をオフにしておく
Grok 4.1 Fast（おすすめ・安い）入力約$0.2／出力約$0.5
Grok 4.5入力$2／出力$6

100万トークンあたりの目安。アプリは安全のため、Fastを少し高め（入力$1.25／出力$2.5）に見積もります。モデル名は更新で変わるので、合わないときは「モデル名を自分で指定」で変えてください。

② 登録の手順

  1. スマホのChromeで xAI のコンソールを開き、登録メール・Google・Xのアカウントで登録できます。console.x.ai
  2. 特典のクレジットがあるか確認ない・条件つきのこともあります。画面の表示が正です。Billing
  3. 必要ならクレジットを追加カードを登録して、必要な額だけ。
  4. 自動チャージ（Auto-recharge）はオフのままにする
  5. APIキーを作るAPI Keys → Create API Key。表示されたキー（xai-…）をすぐコピー。後からは全体を見られません。
xAI コンソールを開く

アプリに登録する

  1. このアプリの「⚙ 設定」を開くホーム右上のボタンです。
  2. 「AIごとの設定」からこのAIを選び、APIキーを貼るキーはスマホの中だけに保存されます。
  3. 上限額と期限日を入れて「保存」入れたクレジットの額と、失効日に合わせます。
  4. 「使うAI」でこのAIを選ぶ声で「◯◯に切り替えて」でも変えられます。

止まる仕組み（Grok）

アプリ①上限額に達する設定で決めた金額（ドル）まで使うと、Grokだけ自動で止まります
アプリ②期限日が来る設定の「期限日」を過ぎると、Grokだけ自動で止まります
会社側残高が0になるクレジットが0になると、xAI側がAPIを拒否します（アプリが「クレジットが切れた」と知らせます）。

止まるとアプリが声で知らせて会話を終えます。ほかのAIは使えます（声で「◯◯に切り替えて」）。使った額はトークン数からの見積もり（目安）なので、正確な残高は各社の画面で確認してください。

気をつけること

  • このアプリのGrokにはWeb検索がありません。
  • 特典のクレジットは期限つきのことがあります。アプリの「期限日」に同じ日を入れておくと、その日に止まります。
  • キーを人に見せたりチャットに貼ったりしない。
  • 料金・特典・モデル名は会社が変えることがあります。
