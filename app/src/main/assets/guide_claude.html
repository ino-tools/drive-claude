Claude を登録して
使う方法

要点：Claudeは先払い（プリペイド）。最低$5（約750円）から入れられ、残高が0になるとAPIが止まります。新規アカウントには試用クレジットが少額つくことがありますが、額や条件は変わります。

① お金の流れ

1回クレジットを購入最低$5。購入から1年で失効、返金不可
残高に入るAPI専用。claude.aiの月額プランとは別の財布です
話すたびに少し減るHaiku 5.5なら1往復で約0.05円。Web検索1回は約1.5円
残高が0で止まる自動チャージ（Auto reload）をオフなら、追加で引き落とされません
Haiku 5.5（おすすめ）入力$0.10／出力$0.50
Sonnet 5.5入力$2／出力$10
Opus 5.5入力$4／出力$20

100万トークンあたりの料金。1日30往復でHaikuなら月に数十円〜数百円の目安です。

② 登録の手順

  1. スマホのChromeで Claude Console を開き、登録メールかGoogleアカウント。電話番号の確認が必要なことがあります。console.anthropic.com
  2. 新規なら試用クレジットを確認画面にバナーが出ていれば受け取る。ない・期限が短いこともあります。Billing（請求）
  3. クレジットを購入（最低$5）Billing → Buy credits。カードを登録します。
  4. 自動チャージ（Auto reload）はオフのままにするオンにすると残高が減るたびに自動で追加購入されます。
  5. APIキーを作るSettings → API Keys → Create Key。名前をつけて作り、表示されたキー（sk-ant-api03-…）をすぐコピー。後からは全体を見られません。
  6. 使った量を見る方法Console の Usage で、モデルごとの使用量を確認できます。
Claude Console を開く

claude.ai のProやMaxの月額プランでは、このAPIは使えません。別の契約です。

アプリに登録する

  1. このアプリの「⚙ 設定」を開くホーム右上のボタンです。
  2. 「AIごとの設定」からこのAIを選び、APIキーを貼るキーはスマホの中だけに保存されます。
  3. 上限額と期限日を入れて「保存」入れたクレジットの額と、失効日に合わせます。
  4. 「使うAI」でこのAIを選ぶ声で「◯◯に切り替えて」でも変えられます。

止まる仕組み（Claude）

アプリ①上限額に達する設定で決めた金額（ドル）まで使うと、Claudeだけ自動で止まります
アプリ②期限日が来る設定の「期限日」を過ぎると、Claudeだけ自動で止まります
会社側残高が0になるクレジットが0になると、Claude側がAPIを拒否します（アプリが「クレジットが切れた」と知らせます）。

止まるとアプリが声で知らせて会話を終えます。ほかのAIは使えます（声で「◯◯に切り替えて」）。使った額はトークン数からの見積もり（目安）なので、正確な残高は各社の画面で確認してください。

気をつけること

  • sk-ant-usr- で始まる文字列はAPIキーではありません。必ず API Keys で作った sk-ant-api03- のキーを使ってください。
  • キーを人に見せたりチャットに貼ったりしない。貼ってしまったら、Consoleで削除して作り直してください。
  • 料金や無料クレジットは会社が変えることがあります。
