完全無料で始める
（Gemini）

最初は完全無料で：GoogleのAI「Gemini」の無料枠なら、お金も、カードの登録もいりません。このアプリはまずこれで動くようにしてあります。

① 無料枠でできること・できないこと

できる

○ 声での会話
○ メモ・予定・SMS・音楽・ランニングの案内
○ 料金は0円

制限

✕ Web検索
△ 回数や速さに制限（使いすぎると少し待つ）
△ 会話内容がGoogleの改善に使われることがある

ランニングのペース案内（キロごとの声）は、AIを使わずスマホの中で作るので、制限に関係なく使えます。

② 無料キーの作り方（5分）

  1. スマホのChromeで AI Studio を開くいつものGoogleアカウントでログインします。aistudio.google.com
  2. 「Get API key（APIキーを取得）」を押す画面の左側のメニューか、上のほうにあります。
  3. 「Create API key（キーを作成）」を押すプロジェクトは「新しいプロジェクト」か、すでにあるものを選びます。お支払いの設定は不要です。
  4. 表示されたキー（AIza…）をコピー長押しでコピーできます。
  5. このアプリで「⚙ 設定」→「AIごとの設定」→ Gemini を開き、キーを貼って保存上限額は0（上限なし）のままで大丈夫です。無料枠なので課金されません。
AI Studio でキーを作る

③ うまく動かないとき

  • 「利用上限」と言われたら、数分待ってからもう一度話しかけてください（無料枠の回数制限です）。
  • モデルによっては無料枠がないことがあります。エラーが続くときは、設定で別のGeminiモデルを選んでください。
  • キーは人に見せたり、チャットに貼ったりしないでください。
  • 画面の名前や場所は、Google側の更新で変わることがあります。

④ もっと使いたくなったら

Web検索がほしいときや回数制限がきついときは、設定の「登録ガイド」から有料枠（先払いで、使いすぎない仕組み）を選べます。
