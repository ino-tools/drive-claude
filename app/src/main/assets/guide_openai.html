ChatGPT（OpenAI）を
登録して使う方法

要点：ChatGPT（OpenAI）のAPIも先払い。最低$5（約750円）から入れられ、残高が0になると止まります。新規の無料クレジットは基本的にありません（あっても少額）。ChatGPTアプリの月額プランとは別の契約です。

① お金の流れ

1回クレジットを購入最低$5（初期値は$10）。購入から1年で失効
残高に入るAPI専用です
話すたびに少し減る安いモデルなら1往復で1円未満
残高が0で止まる自動チャージ（Auto recharge）をオフなら、追加では引き落とされません
GPT-6 Luna（おすすめ・安い）入力$0.10／出力$0.50
GPT-6.1 Sol入力$2／出力$10
GPT-6 Astra（最高性能）入力$10／出力$50

100万トークンあたりの目安。モデル名や料金は更新で変わります。合わないときは、設定の「モデル名を自分で指定」に新しい名前を入れてください。

② 登録の手順

  1. スマホのChromeで OpenAI の開発者ページを開き、登録メールやGoogleアカウントでログインします。platform.openai.com
  2. Billing（請求）でお支払い方法を登録
  3. クレジットを購入（最低$5）Add to credit balance。
  4. 自動チャージ（Auto recharge）はオフのままにするオンだと、残高が減るたびに自動で追加購入されます。
  5. APIキーを作るAPI keys → Create new secret key。表示されたキー（sk-…）をすぐコピー。後からは全体を見られません。
  6. 使った量を見る方法Usage ページで日ごとの使用量を確認できます。
OpenAI の開発者ページを開く

アプリに登録する

  1. このアプリの「⚙ 設定」を開くホーム右上のボタンです。
  2. 「AIごとの設定」からこのAIを選び、APIキーを貼るキーはスマホの中だけに保存されます。
  3. 上限額と期限日を入れて「保存」入れたクレジットの額と、失効日に合わせます。
  4. 「使うAI」でこのAIを選ぶ声で「◯◯に切り替えて」でも変えられます。

止まる仕組み（ChatGPT）

アプリ①上限額に達する設定で決めた金額（ドル）まで使うと、ChatGPTだけ自動で止まります
アプリ②期限日が来る設定の「期限日」を過ぎると、ChatGPTだけ自動で止まります
会社側残高が0になるクレジットが0になると、OpenAI側がAPIを拒否します（アプリが「クレジットが切れた」と知らせます）。

止まるとアプリが声で知らせて会話を終えます。ほかのAIは使えます（声で「◯◯に切り替えて」）。使った額はトークン数からの見積もり（目安）なので、正確な残高は各社の画面で確認してください。

気をつけること

  • このアプリのChatGPTにはWeb検索がありません。天気や最新ニュースは分からないと答えます。
  • ChatGPTのPlusなどの月額プランでは、このAPIは使えません。
  • キーを人に見せたりチャットに貼ったりしない。
  • 料金やモデル名は会社が変えることがあります。
